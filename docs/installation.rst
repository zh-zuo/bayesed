Installation
============

Requirements
------------

- Python >= 3.8
- numpy
- astropy
- pandas

Install from source
-------------------

Clone the repository and install in editable mode:

.. code-block:: bash

   git clone https://github.com/zh-zuo/bayesed.git
   cd bayesed
   pip install -e .

To install development dependencies (for running tests):

.. code-block:: bash

   pip install -e ".[dev]"
